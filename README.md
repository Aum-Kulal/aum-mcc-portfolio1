# Aum Kulal — MCC Computing Portfolio

A responsive portfolio website with five playable games and two computing demonstrations.

## Included
- **PROJECT ORBIT** — turn-based space strategy and resource-management game.
- **DEFENSE PROTOCOL** — tower-defense game with waves, tower placement, credits, and lives.
- **CONNECT FOUR AI** — Connect Four against a depth-limited minimax AI using alpha-beta pruning.
- **NEON SNAKE** — keyboard/on-screen arcade game with collision detection and increasing speed.
- **THE LOGIC LAB** — logic, patterns, probability, and algorithm questions with explanations.
- **PATHFINDING LAB** — interactive maze with BFS and A* search.
- **DATA EXPLORER** — chart and summary statistics using clearly labelled illustrative data.

## Preview
Open `index.html` in a modern browser. No installation or build tools are required.

## Publish on GitHub Pages
1. Sign in to GitHub and create a **public** repository named `aum-mcc-portfolio`.
2. Extract the ZIP file on your computer.
3. Open the extracted folder. Upload `index.html` and `README.md` to the repository's top level (not inside another folder).
4. On GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. Your site address will be:
   `https://YOUR-GITHUB-USERNAME.github.io/aum-mcc-portfolio/`
8. Open that address in a private/incognito browser window to confirm anyone can view it.
9. Paste the public website link into the MCC application.
